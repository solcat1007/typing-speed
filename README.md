# 打字测速 (Typing Speed Test)

## v2.0 更新（2026）

- **多语言词库**：英文 / 中文 / 代码三套文本，外加自定义文本粘贴
- **准确度统计**：错误字符数、准确率实时计算，错误字波浪线高亮，当前字符光标
- **历史成绩图表**：Canvas 柱状图（WPM）+ 折线（准确率），保留最近 10 次成绩
- **完成/换一段/重来**：完整测试流程，完成时自动记录成绩
- **错误高亮与配色**：正确绿色、错误红色波浪线、当前字符描边

**专属彩蛋**：100% 准确率完成解锁「完美无误」；80+ WPM 解锁「键盘闪电」。


在线打字速度测试工具，实时显示 WPM、准确率和用时。

## 功能

- **随机文本**：内置中英文文本库，每次随机选取
- **实时高亮**：正确字绿色、错误字红色下划线、当前字底部光标
- **WPM 统计**：按标准 5 字符/词计算每分钟打字速度
- **准确率**：实时计算输入准确率百分比
- **计时**：从第一次按键开始计时
- **换一段**：随机切换新的测试文本
- **中英文切换**：界面和测试文本同步切换语言
- **全屏模式**：专注测试体验

## 使用方法

1. 用浏览器打开 `index.html`
2. 点击文本区域或直接开始打字
3. 按照显示的文字逐个输入
4. 实时查看右侧的 WPM、准确率和用时
5. 输入完所有文字后自动停止计时
6. 点击"换一段"开始新的测试

## 技术栈

纯 HTML/CSS/JavaScript。

## 彩蛋秘籍

所有小工具共用同一套彩蛋协议（EGG PROTOCOL v2.0）：

| 秘籍 | 效果 |
|------|------|
| `↑ ↑ ↓ ↓ ← → ← → B A` | 全屏彩带烟花 + 触发本应用专属彩蛋 |
| 连点页面标题 5 次 | 打开开发者模式面板 |
| 输入 `solcat` 后按回车 | 启用赛博朋克隐藏主题 |
| `Ctrl + Shift + T` | 切换赛博朋克隐藏主题 |
| 打开浏览器控制台 | 查看 SOLCAT ASCII 署名与解锁提示 |

> 提示：每个应用还藏有一个专属彩蛋，见上方 v2.0 更新说明。
