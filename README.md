# 打字测速 (Typing Speed Test)

在线打字速度测试工具，实时显示 WPM、准确率和用时。

## 功能

- **随机文本**：内置中英文文本库，每次随机选取
- **实时高亮**：正确字绿色、错误字红色下划线、当前字底部光标
- **WPM 统计**：按标准 5 字符/词计算每分钟打字速度
- **准确率**：实时计算输入准确率百分比
- **计时**：从第一次按键开始计时
- **换一段**：随机切换新的测试文本
- **中英文切换**：界面和测试文本同步切换语言
- **全屏模式**：专注测试体验

## 使用方法

1. 用浏览器打开 `index.html`
2. 点击文本区域或直接开始打字
3. 按照显示的文字逐个输入
4. 实时查看右侧的 WPM、准确率和用时
5. 输入完所有文字后自动停止计时
6. 点击"换一段"开始新的测试

## 技术栈

纯 HTML/CSS/JavaScript。
